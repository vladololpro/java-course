Данный репозиторий содержит выполненные практические работы по дисциплине «Основы разработки на Java».

## Структура проекта

Весь исходный код находится в директории `src/main/java/` и разделен по практическим работам:

- `java1/` — Практика 1. ООП (интерфейсы, наследование, полиморфизм, sealed-классы).
- `java3/` — Практика 5. Коллекции и дженерики (List, Set, Map, Queue, PECS, LRU-кэш).
- `java4/` — Практика 6. Строки, числа, время и деньги (String, BigDecimal, java.time).
- `java5/` — Практика 7. Работа с файлами и потоками ввода-вывода.

Все письменные разборы задач и теория находятся в файлах формата Markdown (`Answers*.md`) внутри соответствующих папок практик.

## Тестирование

Для сборки проекта и запуска Unit-тестов используется Maven и JUnit 5.

Запуск всех тестов:
```
bash
mvn test
```

## Сборка проекта

Для компиляции всего проекта используется Maven. Выполните в корне проекта:
```
mvn compile
```
