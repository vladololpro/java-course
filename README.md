# Практические работы по Java

**Студент:** Дорощук Владислав Алексеевич

**Группа:** ИС-542

Данный репозиторий содержит выполненные практические работы по дисциплине «Основы разработки на Java».

## Требования

- JDK 21+
- Maven 3.9+

## Структура проекта

Весь исходный код находится в директории `src/main/java/` и разделен по практическим работам:

- `java1/` — Практика 3. ООП (интерфейсы, наследование, полиморфизм, sealed-классы).
- `java2/` — Практика 4. Ошибки, исключения и первые тесты (JUnit 5).
- `java3/` — Практика 5. Коллекции и дженерики (List, Set, Map, Queue, PECS, LRU-кэш).
- `java4/` — Практика 6. Строки, числа, время и деньги (String, BigDecimal, java.time).
- `java5/` — Практика 7. Работа с файлами и потоками ввода-вывода.
- `java6/` — Практика 8. Лямбда-выражения и Stream API.

Письменные разборы задач и теория находятся в папках практик: `src/main/java/java1/Answers1.md` … `src/main/java/java6/Answers6.md`.

Unit-тесты находятся в `src/test/java/` и разделены по практикам.

## Тестирование

Для сборки проекта и запуска Unit-тестов используется Maven и JUnit 5.

Запуск всех тестов:

```bash
mvn test
```

## Сборка проекта

Для компиляции всего проекта используется Maven. Выполните в корне проекта:

```bash
mvn compile
```

## Запуск

Перед запуском выполните `mvn compile`, чтобы обновить классы в `target/classes`.

```bash
# Практика 3 (Java 1) — подставь нужный номер задачи (task01 … task15)
java -cp target/classes java1.task01.Main

# Практика 4 (Java 2) — демонстрация задач 1–7, задачи 8–15 проверяются тестами
java -cp target/classes java2.Main

# Практика 5 (Java 3) — подставь нужный номер задачи (task01 … task15)
java -cp target/classes java3.task01.Main

# Практика 6 (Java 4) — один общий Main на все 15 задач
java -cp target/classes java4.Main

# Практика 7 (Java 5) — один общий Main на все задачи
java -cp target/classes java5.Main

# Практика 8 (Java 6) — один общий Main на все 7 задач
java -cp target/classes java6.Main
```
